## 📚 Featured Publications

Here are some of my highlighted publications:
- 📖 **Book Publication**: *[Developers guide for building own neural network library: A mathematical journey in creating the neural network library in C++](https://a.co/d/bfDJX3E)*  
A comprehensive guide to understanding neural networks, bridging the gap between theory and practical implementation. This book takes readers on a mathematical journey from the biological neuron to the creation of custom neural network libraries. It introduces core concepts in a digestible manner and gradually deepens the reader's understanding of neural network structures and coding practices.


- 📝 **Paper Publication**: *[Multidimensional Neural Network: Heterogeneous Activation Function on Same Neural Layer](https://dx.doi.org/10.2139/ssrn.4171522)*  
A detailed exploration of advanced neural network architectures, covering various types such as feedforward and feedback networks. The paper delves into the essential computational units—neurons—and their activation functions, which govern the firing of neurons and information transfer across layers. It also discusses innovative architectures involving multiple activation functions on the same layer, advancing the flexibility and computational power of neural networks.
